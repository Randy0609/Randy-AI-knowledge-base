# 40-templates · 可执行资产

> Agent 可以直接复制使用的提示词、任务模板、交付模板。

## 子目录

| 目录 | 用途 |
|------|------|
| `prompts/` | 提示词工程模板（任务拆解、代码审查、交付报告） |
| `tasks/` | 任务模板（功能需求、Bug 修复、调研探针） |
| `delivery/` | 交付模板（检查清单、事故复盘） |

## 使用方式

Agent 在执行任务时，优先从这里取模板，不要从零开始写。
