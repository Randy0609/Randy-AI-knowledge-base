# Agent 工作考核指标

> ⚠️ **V0.1 骨架版**：考核框架。核心原则：**指标用来反映工作质量，不是用来刷的。**

## 第一层：数量底线（及格线）

| 指标 | 目标 | 说明 |
|------|------|------|
| 每周语义 commit 数 | ≥ 5 个 | 每个 commit 代表有意义的推进，不是改一个标点 |
| 每周新增文件 | ≥ 2 个 | 持续产出新内容 |
| 每周文件更新 | ≥ 3 个 | 持续迭代已有内容 |

**反作弊规则**：纯格式修正、一文件拆 N 个 commit、无意义 commit message 不计入。

## 第二层：质量指标（优秀线）

| 指标 | 检测方法 | 标准 |
|------|---------|------|
| 文件结构完整性 | 自动化检查 | 含 frontmatter + 明确大纲 + 交叉引用 |
| 可执行性 | Randy 抽查 | 模板能直接复制使用；Agent 读完能行动 |
| 去 AI 味 | Randy 抽查 | 无禁用词 |
| 内容准确度 | Randy 审阅 | 无编造、引用准确 |

## 第三层：知识复用率（卓越线）

| 指标 | 检测方法 | 目标 |
|------|---------|------|
| Agent 引用率 | 对话中引用仓库内容的频率 | 每 10 次对话 ≥ 3 次 |
| 模板使用率 | 新任务是否使用标准模板 | ≥ 70% |
| 无需重写率 | Agent 查仓库后已有答案 | 每 10 个问题 ≥ 5 个 |
